## API Reference

### Algo Trading REST API (1.0.0)

用于以编程方式访问 Binance 执行算法，以创建和管理现货及期货算法订单.

- `DELETE /sapi/v1/algo/futures/order` — 取消策略订单 (TRADE)
- `GET /sapi/v1/algo/futures/openOrders` — 查询当前策略订单挂单 (USER_DATA)
- `GET /sapi/v1/algo/futures/historicalOrders` — 查询历史策略订单 (USER_DATA)
- `GET /sapi/v1/algo/futures/subOrders` — 查询执行子订单 (USER_DATA)
- `POST /sapi/v1/algo/futures/newOrderTwap` — 时间加权平均价格策略(Twap)下单 (TRADE)
- `POST /sapi/v1/algo/futures/newOrderVp` — 成交量份额参与算法(VP)下单 (TRADE)
- `DELETE /sapi/v1/algo/spot/order` — 取消TWAP策略订单 (TRADE)
- `GET /sapi/v1/algo/spot/openOrders` — 查询当前策略订单挂单 (USER_DATA)
- `GET /sapi/v1/algo/spot/historicalOrders` — 查询历史策略订单 (USER_DATA)
- `GET /sapi/v1/algo/spot/subOrders` — 查询执行子订单 (USER_DATA)
- `POST /sapi/v1/algo/spot/newOrderTwap` — 时间加权平均价格策略(Twap)下单 (TRADE)

### Alpha Trading REST API (1.0.0)

Binance Alpha Trading 的 API。

- `GET /bapi/defi/v1/public/alpha-trade/agg-trades` — 聚合交易查询
- `GET /bapi/defi/v1/public/alpha-trade/fullDepth` — 完整深度（订单簿）
- `GET /bapi/defi/v1/public/alpha-trade/get-exchange-info` — 交易对信息
- `GET /bapi/defi/v1/public/alpha-trade/klines` — K线
- `GET /bapi/defi/v1/public/alpha-trade/ticker` — 24hr价格变动情况
- `GET /bapi/defi/v1/public/wallet-direct/buw/wallet/cex/alpha/all/token/list` — 代币列表

### Alpha WebSocket Market Streams (1.0.0)

通过 WebSocket 访问 Alpha 行情数据流。

- `POST /{symbol}@aggTrade` — 聚合成交流
- `POST /!bookTicker` — 全市场最优挂单流
- `POST /!miniTicker@arr` — 全市场简略行情流
- `POST /!ticker@arr` — 全市场完整行情流
- `POST /came@allTokens@ticker24` — 全部代币 24 小时行情流
- `POST /{symbol}@bookTicker` — 最优挂单流
- `POST /{symbol}@depth{levels}@{interval}` — 部分深度流
- `POST /{symbol}@fulldepth@{interval}` — 全量深度流
- `POST /{symbol}@kline_{interval}` — K 线流
- `POST /came@{contractAddress}@{chainId}@kline_{interval}` — 合约地址 K 线流
- `POST /{symbol}@miniTicker` — 简略行情流
- `POST /{symbol}@ticker` — 完整行情流
- `POST /{symbol}@trade` — 逐笔成交流

### Stocks Trading REST API (1.0.0)

Binance 股票交易 REST API。所有接口位于 `/sapi/v1/equity/*`。

- `GET /sapi/v1/equity/market/exchangeInfo` — 交易规则与 Symbol 列表 (MARKET_DATA)
- `GET /sapi/v1/equity/market/tokenized-assets` — 代币化资产列表 (MARKET_DATA)
- `GET /sapi/v1/equity/market/quote` — 最新报价 (MARKET_DATA)
- `POST /sapi/v1/equity/order/place` — 下单 (TRADE)
- `POST /sapi/v1/equity/order/cancel` — 撤单 (TRADE)
- `POST /sapi/v1/equity/order/cancel-all` — 全部撤单 (TRADE)
- `GET /sapi/v1/equity/order/open-orders` — 当前挂单 (USER_DATA)
- `GET /sapi/v1/equity/order/history` — 订单历史 (USER_DATA)
- `GET /sapi/v1/equity/order/detail` — 订单详情 (USER_DATA)
- `GET /sapi/v1/equity/trade/history` — 成交历史 (USER_DATA)
- `POST /sapi/v1/equity/tokenized/mint` — 铸造代币化资产 (TRADE)
- `POST /sapi/v1/equity/tokenized/redeem` — 赎回代币化资产 (TRADE)
- `GET /sapi/v1/equity/tokenized/convert-status` — 代币化转换状态 (USER_DATA)
- `GET /sapi/v1/equity/tokenized/history` — 代币化转换历史 (USER_DATA)
- `POST /sapi/v1/equity/account/disclaimer` — 签署美股免责声明 (TRADE)
- `POST /sapi/v1/equity/listenKey` — 创建 / 续期 Listen Key (USER_STREAM)

### Stocks Trading WebSocket Streams (1.0.0)

Binance 股票交易的 WebSocket 流定义。基础 URL：wss://nbstream.binance.com/equity

- `POST /price` — 价格流
