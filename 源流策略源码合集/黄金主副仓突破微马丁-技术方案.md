> 风控目标：最大逆向 200 点不爆仓；最大回撤 ≤ 200 美元（=100% 初始资金）

## 0. 设计定位与核心决策

- **组合级风控语义**（用户已确认）：
  - 主仓"止损 150 点" → **组合级逆向距离止损**：以全部持仓（主+副）加权平均成本为锚，逆向 150 点即全平。
  - "组合硬止损 180 美元" → **组合级金额止损**：全部持仓合计浮亏 ≥ 180 美元即全平。两条并存。
  - "移动止损 50 点" → **组合级移动止损**：组合浮盈点数达 30 点（可配）启动 → 先移保本 → 再以 50 点距离跟随组合峰值；**副仓激活期间冻结上移**；被扫到即全平。
- **主/副仓双 ticket 状态机**替代一单一结的 `m_lastTicket` 单票模型：主仓 magic 与副仓 magic 分离。
- **禁止无限马丁的 4 道硬闸**：副仓最大层数 4 / 单层手数上限 0.05 / 最大总手数 0.15（硬上限 0.20）/ 组合硬止损 180 美元，全部开仓前逐级校验。
- 所有点位一律经 `PointMultiplier`（黄金 3/5 位小数 ×10）换算，**禁止硬编码 0.01**。

### 1.2 主/副仓双状态机模型

```

g_subMagic  = InpMagicNumber*10 + 2   // 副仓标记
```

- **方向互斥**：同一时刻只允许一个方向组合（全多或全空）。突破反向信号不反手，等组合全部平仓后由新 K 线重新评估。
- 遍历用 `PositionSelect`/`PositionGetInteger(POSITION_MAGIC)` 按 magic 集合过滤，结果写入 `BasketState` 结构，全 Tick 复用。
- 层号不靠手数反推，靠**每层开仓时注释** `"GOLD_MM_L"+层号`（`POSITION_COMMENT`），稳健于部分平仓场景。

### 1.3 OnTick 主流程调用链

```
OnTick()
└─ ① 刷新与窗口检查
   ├─ SymbolInfoTick(tick)
   ├─ CheckDailyReset()                  // 跨日重置当日统计
   ├─ g_isFridayWindow = IsFridayWrapUpWindow(TimeCurrent())
   ├─ g_newsBlocked    = IsUpcomingNews() // 前后15分钟
   ├─ g_spreadBlocked  = CurrentSpreadPoints() > InpMaxSpread(50)
   └─ 若 g_dailyStopTriggered → 仅执行②+③(强平管理), 返回
└─ ② 组合持仓扫描
   └─ ScanBasket()                       // 填 BasketState
└─ ③ 出场检查 (优先于加仓/开仓)
   ├─ CheckExitA()   组合浮盈 ≥ 组合止盈金额
   ├─ CheckExitB()   主仓浮盈 ≥ 副仓浮亏 且 整体浮盈>0
   ├─ CheckExitD()   组合浮亏 ≥ 180$ 或 距加权成本 ≥150点
   ├─ CheckExitFriday() 周五收盘前30分钟全平
   └─ CheckTrailingStopBasket()  组合级移动止损(含保本) → 扫到即 C 全平
└─ ④ 加仓检查 (有主仓且主仓浮亏≥30点 才进入)
   └─ TryAddSubLayer()                   // 层数/总手数/保证金预检
└─ ⑤ 开仓检查 (仅新K线触发)
   └─ 若 组合空仓 且 无风控封锁 → 刷新 Donchian 通道 → CheckBreakoutOpen()
└─ ⑥ 每日风控 & 日志
   └─ UpdateDailyStats(); DebugLog();
```

阶段顺序原则：**出场永远先于加仓、加仓先于开仓**；副仓激活后冻结新主仓开仓信号。

## 4. 关键算法详解

设 `PPS = PointMultiplier`（黄金 5/3 位=10，4 位=1）；`dp = PPS×_Point`；`tv = SYMBOL_TRADE_TICK_VALUE`；`ts = SYMBOL_TRADE_TICK_SIZE`。

**4.1 点数→价格**：`price = anchor ± points×PPS×_Point`（例：黄金3位，30点 = 30×10×0.001 = 0.30 美元）

**4.2 组合加权均价**：`wac = (Σ vol_i×open_i) / Σ vol_i`

**4.3 组合浮盈（美元）**：`totalPL = mainPL + subPL`（`PositionGetDouble` 累加，含 swap+commission）

**4.4 浮盈点数**：`totalPLPoints = (dir=+1) ? (bid-wac)/dp : (wac-ask)/dp`

**4.5 200 点压力测试**（每次开/加仓前）：
```
advPrice    = (dir=+1) ? bid - 200×dp : ask + 200×dp
adverseLoss = Σ_{全部含新单} vol_i × (tv/ts) × |open_i - advPrice|
marginUsed  = OrderCalcMargin(type, _Symbol, V+addLot, advPrice)
pass = (adverseLoss + marginUsed) ≤ equity × 0.90
```

**4.6 副仓手数序列**：`lot_i = min( NormalizeVol(InpSubFirstLot × InpSubFactor^(i-1)), InpSubMaxLot )`
- 默认：0.01 → 0.01 → 0.02 → 0.02，总手数 0.07 ≤ 0.15 上限（合规，预留大量余量）
- 若调高首层 0.02：0.02+0.03+0.03+0.04=0.12，仍在 0.15 内
- 0.05 首层×4 层 = 0.20 恰好触及硬上限 → **首层+上限需联动校验**

**4.7 副仓触发阈值（主仓逆向点数，用户已确认主仓浮亏为锚）**：
```
T_1 = InpSubTrigger(30)
T_k = T_1 + (k-1)×InpSubGridPoints                       // 恒定间距(默认)
T_k = T_1 + Σ_{i=1}^{k-1} InpSubGridPoints×1.3^(i-1)     // 放大间距(默认关)
第k层加仓条件:  mainPLPoints ≤ -T_k    (主仓浮亏点数)
```

**4.8 单笔主仓风险反推手数**：`lot = min(InpMainLot, floor(riskUSD/riskPerLot/VOLUME_STEP)×VOLUME_STEP)`，其中 `riskUSD = equity×2%`，`riskPerLot = tv×PPS×150/ts`

**4.9 出场 B 判定（美元比较，注意方向）**：
```
mainPL ≥ -subPL    // 主仓浮盈覆盖副仓浮亏
totalPL = mainPL + subPL > 0   // 组合整体为正
```

## 7. 风险边界与限制（禁止无限马丁）

### 7.1 硬性封顶清单（代码内三重校验：input 默认值 + MathMin + 独立常量兜底）
| 维度 | 封顶 | 兜底 |
|---|---|---|
| 副仓层数 | `InpSubMaxLayers=4` | 代码 `MathMin(InpSubMaxLayers,5)` |
| 单层手数 | `InpSubMaxLot=0.05` | 同上 |
| 总手数 | `InpMaxTotalLots=0.15` | `InpHardMaxLots=0.20` 不可被优化突破 |
| 组合硬止损 | 金额 180$ + 距离 150点 | 双条件并存 |
| 每日亏损 | 30$ 含浮动 | 达后停开+可强平 |
| 压力测试 | 200点逆向浮亏+保证金 ≤ 净值90% | 每次开/加仓执行 |

### 7.2 最大逆向 200 点回撤测算（保守估计）
- 触发节奏：主仓浮亏 30 点 → 第 1 层；此后主仓浮亏每 20 点一层 → **90 点内 4 层全部触发**
- 手数序列（默认）：主 0.01 + 副 0.01+0.01+0.02+0.02 = **0.07 总手数**，远低于上限
- 200 点逆向时最坏浮亏 ≈ 10~14 美元；保证金 ≈ 5~8 美元；**浮亏+保证金 ≈ 15~22 美元 ≤ 净值×90%（180 美元）**，极端安全
- 若调参到边界（0.05 首层×4 层 = 0.20 手）：200 点最坏浮亏升至 25~35 美元，仍 ≤ 180$ 硬止损 → **180$ 组合硬止损即"不爆仓"最终保险丝**（20000 美分净值 90% 阈值 18000 美分 = 硬止损 180$ 对齐）
