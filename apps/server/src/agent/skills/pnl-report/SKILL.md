# 收益报告体例

当用户要求「收益报告 / 这周赚了多少 / 月度总结」这类汇总性问题时，按以下步骤与模板输出，不要自由发挥体例。

## 步骤
1. 先确定区间：以 system prompt 中的当前北京时间为准，把「今天/本周/本月」换算成起止日期。
2. 调用 `get_pnl_summary`（period 用 today/7d/30d/this_month/custom）取交易所权威口径：已实现盈亏、手续费、资金费。
3. 调用 `get_daily_pnl`（days 覆盖区间天数）取按日已实现明细。
4. 调用 `list_recent_baskets` 取区间内已了结篮子的整体盈亏（净口径，含浮动部分的最终落定）。
5. 所有数字必须来自工具返回；缺哪项就写「数据不可用」，禁止口算补齐。

## 输出模板（飞书 markdown）

```
【收益报告】{区间描述}（环境：{demo/live 标注}）
已实现净盈亏：{x} USDT
- 手续费合计：{x} USDT
- 资金费合计：{x} USDT
逐日：{日期} {±x} / {日期} {±x} ...（超过 7 天只列盈亏最大与最小的各 3 天）
了结篮子：{n} 轮，胜 {n} / 负 {n}，最佳 {code} {+x}，最差 {code} {−x}
口径说明：以上为净口径（已扣双边手续费），与币安 App 毛口径不可直接对比。
```

## 纪律
- 不做预测、不给加减仓建议；报告结尾如需风险提示，仅可引用平台既有口径说明。
